146 clay plaster colours

Tap any colour to see it large, then use Previous and Next, the arrow keys or a swipe to move through the range. The palette here is a stand-in, your 146 supplied colours replace it.

How this runs in Webflow

  1. One CMS collection, 146 items. Each colour has a name, code, family, hex value, a swatch photo and an enlarged photo, so adding a colour later is a new CMS item, not a design job.
  2. One Collection List renders the grid. The family filter and the enlarged view are a small script on top, so the page still works and stays crawlable without it.
  3. Previous and Next follow the current filter, so someone browsing ochres only steps through ochres.
  4. Every colour has its own link, so you can send a client straight to one shade.
  5. Photos win over hex. If a swatch photo exists it's shown, so the real trowelled texture comes through; the hex value is the fallback while photos are being shot.
